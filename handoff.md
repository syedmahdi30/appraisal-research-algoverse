## Failed Attempts

- **The Claude Design PDF export is unusable.** Its `Producer` is `macOS Quartz PDFContext` (Print →
  Save as PDF), which paginates onto US Letter and clipped everything past 612pt — the bars, the
  4–5×, joy → sadness, and both the PATCHING and STEERING panels. ~40% of the artwork and every
  result. This is the print path's behaviour, so it recurs on any re-export. Re-port from the
  canvas source instead.
- **A 2200px canvas cannot be scaled into a 5.5in figure.** 22px body text lands at ~4pt. Type must
  be re-typeset, not resized. Measured, not estimated: 8pt regular runs 17.4 chars/inch but 8pt
  **bold caps only 12.8**, so headings run out of room first.
- **The figure cannot go on page 1.** `[t]` after `\maketitle` floats *above the title*; `[t]`,
  `[!t]`, `[h]`, `[!h]` after the abstract all fall to page 2 because the title block plus a
  257-word abstract leave under 3.5in. `[H]` (float package) costs a page and still lands on page 2.
  Page 1 requires shortening the abstract. **Cutting related work does not help** — that space is on
  pages 2–3.
- **Figure width is not the page-cost lever.** At 0.72\linewidth it was still 9pp; the cost is
  page-boundary displacement, not figure height.
- **The `\ifshort` branch trap bit four times this session**, always silently. `\section{Conclusion}`,
  `\paragraph{Limitations.}` and `sec:minimal` all exist in both branches. A filler probe reported
  "fits" because it landed in the short branch. **Always confirm which branch an anchor is in.**
- **I claimed the Gemma metrics `verdict` string was stale. It was not** — that file carries both
  `probe` and `val` per group, and the verdict correctly reads `probe`. I had compared a `val`
  extraction against a `probe` summary.
- **I claimed `tab:patching` was an orphaned label. It was not** — tables live in `paper/tables/`
  and I had grepped only `neurips_2026.tex`.
- **Do not trust "image 0%" as a result.** It was framed as a finding twice before being corrected.
